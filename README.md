# 🚀 YT-Control — Official Release Distribution Channel

This repository serves as the official distribution channel for signed production releases, cryptographic manifests (`latest.json`), and installer packages for **YT-Control Desktop** (macOS and Windows).

- Source code repository remains strictly private at `mienetic/YT-Control`.
- All release artifacts are cryptographically signed using Minisign (Ed25519) and verified prior to execution.
